# Ícones

Ícones do conjunto **Material Symbols** (Google), estilo *Outlined*, baixados de
<https://github.com/google/material-design-icons> (mesmos ícones de
<https://fonts.google.com/icons>). Licença **Apache 2.0** (texto completo em `LICENSE`): uso livre,
inclusive comercial, desde que a licença acompanhe os arquivos — por isso ela vai junto no `.exe`.

O SVG fica como foi baixado (preto); o programa pinta na cor do tema ao carregar
(`interface/tema_icones.py`). Aprovados pelo usuário por foto em 2026-11-10.

| Arquivo | Onde aparece |
|---|---|
| `calendar_month.svg` | Botão de abrir o calendário, em todos os campos de data |
| `search.svg` | Lupa nos campos de pesquisa |
| `straighten.svg`, `tune.svg`, `event_note.svg`, `delete.svg` | Abas Instrumentos, Calibrar, Cronograma, Lixeira |
| `add.svg` | Novo instrumento, Novo plano, Adicionar ponto |
| `edit.svg` | EDITAR, EDITAR PLANO, Renomear plano |
| `visibility.svg` | VER PLANO, Ver calibração |
| `delete.svg` | Enviar … para a Lixeira |
| `restore_from_trash.svg`, `delete_forever.svg` | Restaurar e Excluir permanentemente (Lixeira) |
| `show_chart.svg`, `download.svg` | Gráfico de tendência e Salvar imagem (PNG) |
| `swap_horiz.svg` | Mudar condição |
| `add_location_alt.svg` | Mais um local |
| `lock_open.svg`, `lock.svg` | Modo edição / Modo consulta (canto superior direito) |
| `check_circle.svg`, `error.svg`, `warning.svg` | Avisos ✔ (certo), ✖ (erro), ⚠ (aviso) |
| `refresh.svg`, `back_hand.svg` | Atualizar e Pedir edição (modo consulta) |
| `picture_as_pdf.svg` | Aba Certificados e botão Abrir PDF |
| `attach_file.svg` | Adicionar certificado (PDF) / Substituir certificado (PDF) (Nova calibração e EDITAR da calibração) |
